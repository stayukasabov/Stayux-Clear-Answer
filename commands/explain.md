# Explain a topic

Explain the topic in the argument as one reply. Follow the workflow of
`/clear-answer:on` for this reply.

Clear Answer is a translation, not a summary. Give the content that the topic
needs. Only the sentences change.

For a file, use one of these commands:

- `/clear-answer:explain:diagram`: a Markdown file with a Mermaid diagram.
- `/clear-answer:explain:html`: a self-contained HTML page with a diagram.
